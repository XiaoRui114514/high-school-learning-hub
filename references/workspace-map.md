# 工作区地图与文件约定

> 如果当前没有工作区，skill 自带的 `textbooks/` 使用同样的 `0X_学科/01_官方教材/` 结构；仅定位教材时把 `textbooks/` 当作根目录。它不是个人学习工作区，不在这里创建个人记录、记忆或错题；需要留档时再确认工作区路径。

## 1. 顶层结构

```
高中学习中枢/
├─ AGENTS.md                    # 轻量入口：任务路由（每次自动读取）
├─ README.md                    # 完整说明与手动上传教材流程

```

## 4. 教材 INDEX 与页码规则

`INDEX.md` 是教材的**唯一检索入口**：

- 每条小节通常含：教材页码、PDF 页码、核心知识点、例题/练习/实验/图表位置、前置知识。
- 先按章节号/标题关键词定位，只读命中条目；不要全文读索引。
- **PDF 页码 = 教材页码 + 偏移**。偏移因教材而异，以 INDEX 记录为准；更换教材文件后必须重新抽样核验，旧偏移不自动沿用。
- 「教材页码」是书上印刷页码；「PDF 页码」是阅读器页序。引用时写清楚是哪一种。
- 例题/练习/实验/图表位置若标记「待首次学习时回填」，必须先读原页确认再引用，不得凭目录猜测。
- 图片、图表、实验装置、例题排版以原页渲染图为准，不能只看文字提取。
- 日常阅读优先用 `Word/`：定义、公式、关键词、例题/练习文字从 Word 读取。
- Word 识别不到、缺字/乱码、图表/公式不清或内容有误时，回 `PDF/` 原页核对；教材页码、图片、实验、例题/练习排版与最终校对以 PDF 为准。
- Word 与 PDF 冲突时，以 PDF 原版为准。

## 7. 工具

```powershell
# 自检（cwd = 工作区根目录）
py -3 08_系统工具/检查工作区.py

# 读 Word 教材：先看目录/关键词，再按段落读（工作区或 textbooks/ 均可）
py -3 scripts/extract_word_text.py "0X_学科/01_官方教材/Word/xxx.docx" --outline
py -3 scripts/extract_word_text.py "0X_学科/01_官方教材/Word/xxx.docx" --grep "集合" --context 1
py -3 scripts/extract_word_text.py "0X_学科/01_官方教材/Word/xxx.docx" --start 76 --end 95

# 按教材页码提取 PDF 文字（Word 识别不到/错误时使用）
py -3 08_系统工具/提取教材页.py "0X_学科/01_官方教材/PDF/xxx.pdf" --教材页 2 --offset 7

# 渲染 PDF 教材页为图片
py -3 08_系统工具/提取教材页.py "0X_学科/01_官方教材/PDF/xxx.pdf" --教材页 2 --offset 7 --image --out tmp/教材页
```

- 依赖：Python 3.8+；`pypdf`、`pypdfium2`、`Pillow`。Word 提取只用标准库；缺失依赖时脚本会提示安装命令。
- 自检覆盖：目录结构、必需文件、公共文件与模板、教材文件完整性、重复文件、空目录。
- 本 skill 的 `scripts/` 下有同名功能的可移植版本；若工作区已有 `08_系统工具/`，优先用工作区版本。
- skill 自带教材在 `textbooks/0X_学科/01_官方教材/`；没有工作区时可直接读这里的 PDF/Word。

## 8. 维护原则

- 目录与文件名保持稳定（缓存友好）；不要随意改名或移动 `00_学习控制中心/`、`00_学科记忆/`、`INDEX.md`。
- 整体备份：复制整个文件夹；临时渲染图片（`tmp/`、`教材页输出/`）可不备份。
- 最有价值的部分：`00_学习控制中心/`、各学科 `00_学科记忆/`、`05_错题/`、`06_学习记录/`、`08_讲题提示/`，可单独再备一份。
