# 记忆规则

> 目的：让工作区**记得有价值的信息，而不是记得所有信息**；避免记忆污染与虚假学习记忆。

## 1. 记录分层（最重要）

| 层次 | 位置 | 内容 | 生命周期 |
| --- | --- | --- | --- |
| 原始学习记录 | `0X_学科/06_学习记录/YYYY-MM-DD.md` | 当天学了什么、做了哪些题、用户原始答案、批改结果、表现与问题 | 长期保留，作为历史事实 |
| 讲题提示卡 | `0X_学科/08_讲题提示/提示卡.md` | 用户要求保留的讲题小毛病线索：简短证据、下次最小提示、自主辨识情况 | 讲题时按需读取；重复出现才升级 |
| 长期记忆 | `0X_学科/00_学科记忆/`、`00_学习控制中心/` | 从原始记录或多次观察提炼的稳定结论 | 达到门槛后写入，可升级/降级 |
| 错题 | `0X_学科/05_错题/` | 反映知识/方法漏洞的题目与完整错因 | 归档保留，参与复习 |

**不要混层**：原始记录保留事实；提示卡是待验证线索，不是错题库；长期记忆不粘贴完整对话与整道题。

## 2. 可以进入长期记忆的内容

- 稳定的学习习惯与讲解偏好（经多次验证更有效/更无效的方式）。
- 经过多次观察确认的薄弱点与错误模式。
- 多次证明稳定的优势。
- 教材进度与掌握状态（有明确证据）。
- 长期目标与阶段目标。
- 已形成的重要学习经验（可迁移方法）。
- 教材版本、章节结构、页码索引等客观信息。

## 3. 不得进入长期记忆的内容

- 一次性的对错、一次性的情绪与状态。
- 完整聊天记录、整道题原文。
- 未经证实的推测。
- 与学习无关的个人信息、隐私与凭证。
- 与教材冲突、来源不明的结论。
- 重复内容（同一结论已存在时只更新原条目）。

## 4. 可信程度与升级路径

| 次数 | 标记 | 写入位置 |
| --- | --- | --- |
| 1 次 | 【观察】 | 当天学习记录；用户要求个性化讲题提醒时，可在提示卡留带日期的待验证短摘要 |
| 2–3 次（同类、不同情境） | 【多次观察】 | `COMMON_MISTAKES.md` |
| 多情境多次验证 | 【已确认】 | `WEAKNESSES.md` |

优势同理：一次做对不写入 `STRENGTHS.md`，需多次、不同情境稳定表现。

## 5. 判断「长期弱点」

满足其一即可考虑：

- 同类错误在 2 次以上不同题目/情境中出现。
- 分析后确认属于概念性、结构性漏洞（而非偶然计算失误）。
- 反复需要前置知识补救（基础链条断裂）。
- 复习后仍反复出错。

判断前必须给出**表现证据**（题目情境、错误表现），不能只有结论。

## 6. 判断「已经掌握」

- 能独立完成教材相应练习，并解释理由（不只是得出答案）。
- 换一个情境或换个问法仍能正确处理。
- 能在无提示条件下说出关键条件、适用范围与常见错误。
- 复习间隔后仍稳定（至少经过一次间隔复习）。

仅凭「讲懂一次」不算掌握；仅凭「做对一次」不算掌握。

## 7. 掌握等级的升降

| 动作 | 条件 |
| --- | --- |
| 升级 | 该等级要求在**独立**完成条件下连续满足 2 次以上 |
| 降级 | 在复习或新情境中出现基础性错误，且错误来自该知识点本身 |
| 标记「需要复习」 | 超过合理间隔未接触且曾出现错误，或错误重现 |

降级不是惩罚，只用于调整教学难度与复习优先级。历史记录不删除。

## 8. 冲突处理

1. **新证据 vs 旧记忆**：以新证据为准，但保留变化说明（如「原为易错，现明显改善，继续观察」）。
2. **教材 vs 其他资料**：以教材原版页面为准；教材未确认前不下定论。
3. **学科记忆 vs 总记忆**：具体知识点归学科记忆；跨学科共性才写入总记忆。
4. **用户自述 vs 实际表现**：两者不一致时都记录，并注明来源（用户自述 / 观察）。

## 9. 避免记忆污染

- 写入前先查是否已有同类条目；有则更新而非新增。
- 每条记录含：证据、可信程度、日期。
- 不把「知识点名称」当作「错误原因」；写清错在哪一步。
- 不把版本、页码等客观信息与主观判断混在同一表格。
- 每 2–4 周检查 `WEAKNESSES.md` 与 `COMMON_MISTAKES.md`：合并重复、标注已改善、删除纯属偶然的条目。

## 10. 进度更新

- 进度以教材章节为单位，不按刷题量。
- 只有完成「讲解 → 例题 → 练习 → 批改 → 总结」才更新 `PROGRESS.md` 对应行。
- 每次只改受影响的行，不重写整表。
- 掌握状态：未学习 / 刚接触 / 基础理解 / 基本掌握 / 熟练 / 容易出错 / 综合应用较弱 / 需要复习。
- 复习安排写入该学科 `REVIEW_PLAN.md`，不重复散落在其他文件。

## 11. 维护清单

- [ ] 长期弱点是否都有证据与可信程度标记？
- [ ] 是否有条目已明显改善但状态未更新？
- [ ] 是否有重复条目需要合并？
- [ ] `PROGRESS.md` 与实际学习记录是否一致？
- [ ] `REVIEW_PLAN.md` 是否有过期未处理项？
- [ ] 学科记忆之间是否有矛盾结论？
