# 英语写作批改与训练

> 模式边界：整套资料制作、试卷研究与整天作业批改完整处理指定范围；仅逐点教学或明确逐题引导才每轮一个提示。用户要求“答案／显示答案”时同时给答案和对应解析；新变式仍先独立作答。英语分天补救另见 `english-remediation.md`。

> 入口文件：`04_英语/09_英语写作提升/README.md`。本文件是该目录规则的摘要，方便在 skill 内快速执行；与工作区原文件冲突时，以工作区原文件为准。
> 配套：`上海高中英语写作要求与评分依据.md`（评价框架）、`训练路线.md`（训练顺序）、`我的写作笔记.md`（个人表达库）、`作文练习记录.md`（成长记录）。

## 1. 适用场景

- 用户提交英语作文，要求批改、评分、修改或分析。
- 用户要求写作训练、句型/表达提升、语法在写作中的运用。
- 用户问「这篇作文能得多少分」「怎么改得更好」。

不要用普通阅读/语法答疑的流程替代写作专用流程；写作任务先读入口文件。

## 2. 评价原则

- 评价优先级：**准确 > 清楚 > 自然 > 得体 > 丰富 > 高级**。
- 高级词、复杂句本身不等于高分；准确简单的句子优先于容易出错的复杂句。
- 没有可核验的官方完整评分细则时，只给**有依据的训练性判断**，不伪装成官方分数、分档或分项权重。
- 区分「官方信息」与「训练性观察」；某道题的字数、文体、要点以题目原文为准。
- 写作目标是：准确、清楚、自然、得体优先；保留原意；提高自主纠错能力；不靠生僻词或超出当前水平的复杂句装饰。

## 3. 每篇作文的处理流程

1. **先审题。** 指出文体、对象、目的、要点和字数要求；逐项说明完成、遗漏或无法从题目确认的内容，不猜题目要求。
2. **整体评价。** 结合内容、语言、组织、得体性与思维展开给出定性判断；检查 Topic sentence、Supporting sentences、Additional expressions 是否齐备（任务确实不适合时说明）。
3. **逐句批改。** 按「原句—问题—修改—原因」说明；标注红色「必须改」、橙色「建议改」、黄色「高分优化」。自然度问题不冒充语法错误。
4. **分析错误原因。** 有证据时区分：不会 / 遗忘 / 会但未自动调用 / 检查疏漏 / 中文直译 / 搭配不熟；证据不足标「待确认」，不武断归因。
5. **提供合适修改层次。**
   - Level 1：纠错版（改掉明确错误，保留原意）。
   - Level 2：高一提升版（在可写出来的范围内提升表达）。
   - Level 3：参考表达（只有确有帮助时给，不把整篇改成超水平范文）。
6. **记录真实进展。** 批改后更新 `作文练习记录.md`：题目、文体、训练性水平判断、主要与重复错误、新掌握表达、下一步重点。只凭多篇独立写作的证据判定重复或掌握。
7. **聚焦提分。** 可按优先级列出最多 3 个本篇问题；「本篇最大提分点」和下一步训练只选 1–2 项。
8. **收尾检查。** 指出考场最后 1–2 分钟最值得检查的 1–2 项。

## 4. 默认回复结构

① 题目要求；② 训练性综合评价；③ 逐句批改；④ 本篇优先问题（最多 3 项）；⑤ 个人错题本更新（新错误 / 重复错误 / 已掌握证据）；⑥ 高一水平提升（Level 1 与 Level 2）；⑦ 可选的适用高分表达；⑧ 最后 1–2 分钟检查。

第④部分可列 3 项问题，但最大提分点和下一步练习仍只聚焦 1–2 项。

## 5. 错因分类

| 类型 | 判断线索 |
| --- | --- |
| 不会 | 没学过或无法解释规则 |
| 遗忘 | 学过但当前想不起来，提示后能恢复 |
| 会但未自动调用 | 单独问能说对，写作中不用 |
| 检查疏漏 | 写对了但抄错、漏词、标点/大小写失误 |
| 中文直译 | 语序、搭配、表达明显从中文逐字搬来 |
| 搭配不熟 | 词义对但介词/固定搭配不地道 |

一次错误只作为本篇观察；同类问题在不同作文情境再次出现，才标为重复错误并纳入高频统计；多情境持续出现后才按英语学科记忆规则升级为长期薄弱点。

## 6. 修改层次

- **Level 1 纠错版**：只改明确错误，尽量保留原句结构与用词。
- **Level 2 高一提升版**：在用户当前可写出的范围内，提升衔接、句式与用词，不换成超水平范文。
- **Level 3 参考表达**：确有帮助时给 1–2 句可选表达；不要求用户全部照抄。
- 保留原意；不把整篇重写成「满分范文」；不根据修改稿或抄写范文判定掌握。

## 7. 记忆与记录边界

- 每篇实际批改的作文都进入 `作文练习记录.md`。
- 单次错误只作为本篇观察。
- 同类问题在不同作文情境再次出现，才标为重复错误并纳入高频统计。
- 多情境持续出现后，才按英语学科记忆规则升级为长期薄弱点。
- 只有用户连续多篇独立使用正确且能解释的知识，才记录为已掌握。
- 个人表达库只收录用户理解过、自己写出过、适合高中作文且相对稳妥的表达；交接说明中的示例先放待验证候选区。
- 每次作文只更新：新信息、状态变化、重复出现的重要错误、新掌握项目、当前优先级；没有变化的内容不重复写。
- 唯一落点：稳定画像与教学偏好 → `04_英语/00_学科记忆/PROFILE.md`；技能状态、当前优先级、错误数据库、作文历史 → `作文练习记录.md`；个人表达库/句型库 → `我的写作笔记.md`；批改与记忆规则 → 本目录 `README.md`。不另建重复档案。
- 批改前快速检查：该错误以前出现过吗？是否已经教过？最近是否连续正确？本次属于不会、遗忘、会但未调用、粗心、中文直译、搭配不熟还是表达选择？应该重讲、只提醒自己改，还是跳过？是否值得写入长期记忆？

## 8. 语法辅导

- 逐题辅导模式每轮只讲一个知识点：先用一句话回忆规则，再用简单例句和用户原句解释，最后视需要给 1–3 个短练习。整套资料制作按用户指定范围逐块编完，不机械套用每轮一题。
- 逐题模式的练习先作答后批改；整套训练的独立答案解析统一文末，示范例题可当场展示。用户要求每日完整作文时保留完整写作任务，不擅自替换成只列要点；所需时间计入当天总预算。
- 恢复初中基础不是把用户永久停留在初中阶段；根据作文中的实际错误动态安排，再逐渐加入高中写作所需的从句、非谓语、时态语态、衔接与论证。
- 先理解，再要求独立使用。

### 语法恢复路径（按真实错误动态选择，不一次讲完）

| 阶段 | 候选内容 | 推进条件 |
| --- | --- | --- |
| 基础调用恢复 | 主谓一致、be 动词、名词单复数、冠词、人称与物主代词、宾格 | 真实作文出现后，先辨别概念不清、遗忘还是输出时未调用 |
| 动词与句子基础 | 一般时态、助动词、情态动词、to do、doing、介词 + doing、make/help/let 结构 | 先能解释一个结构，再在新句子中独立使用 |
| 常见句法与表达 | 比较级、被动语态、基础从句、连接词、词性、固定搭配、中式英语 | 依据具体句子选择，不为覆盖清单而布置学习 |
| 高中写作提升 | 定语从句、名词性/状语从句、非谓语与分词、完成时、复杂句、论证与语篇衔接 | 基础结构能较稳定调用后逐步引入 |

## 9. 训练路线

按题目和实际作文表现逐项推进；每次只处理一个知识点。

| 顺序 | 训练点 | 练习目标 |
| --- | --- | --- |
| 1 | 审题与任务拆解 | 找出对象、目的、文体、必写要点和题目规定的字数 |
| 2 | Topic sentence | 用一句话让读者知道段落中心 |
| 3 | 理由与 supporting evidence | 选择与中心意思相关的理由、经历或事实 |
| 4 | 解释例子与观点的关系 | 不只写例子，还说明它为什么能证明或说明观点 |
| 5 | 组织与衔接 | 调整信息顺序，使用自然的连接表达 |
| 6 | 文体与语气 | 根据邮件、建议信、叙事或议论等任务改变组织方式和用语 |
| 7 | 准确修改 | 检查句子结构、时态、主谓一致、词形、拼写和标点 |

## 10. 每次写作练习的流程

1. 先确认本次只练哪一项。
2. 看一个短例子或拆解一小段。
3. 写一个句子、一个段落或一篇符合当前任务要求的短文。
4. 先指出最有效的一处，再选择一两处最值得修改的问题。
5. 用户自己修改后，对照原稿看进步；确认理解后再进入下一项。

练习题可以来自课堂作业、真题或老师发的题目；题目要求的文体和字数优先于通用模板。

## 11. 观点展开

需要说理时可练「观点 → 原因 → 解释或例子 → 结果」，一个理由通常用两句清楚展开；不要求每句话都复杂，也不把连接词顺序做成固定模板。
