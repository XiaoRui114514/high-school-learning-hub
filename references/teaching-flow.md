# 教学流程详解

> 配套 `SKILL.md` 使用。这里展开「教材章节学习、讲题、批改、复习」的具体动作与边界。

## 一、教材章节学习（类型 D）

### 1. 开课前：定位与核对

1. 读 `0X_学科/01_官方教材/INDEX.md`，用章节号/标题关键词定位，只读命中条目。
2. 从条目中取：教材页码、PDF 页码、核心知识点、例题/练习/实验/图表回填状态、前置知识。
3. 打开 PDF 对应页（`PDF页码 = 教材页码 + 偏移`）。偏移以 INDEX 为准；换教材文件后必须重新抽样核验，旧偏移不自动沿用。
4. 以原页为准核对：板块名称、例题编号、练习编号、图表、实验装置、页码。图片/图表/实验排版必须看渲染图，不能只依赖文字提取。
5. 检查 INDEX 中该节的例题/练习/实验位置是否已回填。未回填就现场读原页确认，不凭空引用；确认后回填 INDEX。
6. 日常阅读优先用 `Word/`：定义、公式、关键词、例题/练习文字从 Word 读取。Word 识别不到、缺字/乱码、表格/图片/公式不清或内容有误时，回 `PDF/` 原页核对；页码、图片、排版与最终校对以 PDF 为准。

### 2. 开课第一句：说明范围

先向用户说明真实存在的板块与页码，例如：

> 本节教材学习范围如下：1.1 集合初步（教材第 2–12 页，PDF 第 9–19 页）。包含：集合与元素、属于关系、集合表示法、子集与相等、交集/并集/补集，以及教材例题与练习。我们每次只推进一个知识点。

要求：

- 只列真实存在的板块，不套模板硬凑。
- 页码必须来自 INDEX 与原页核对。
- 说明本次从哪一小块开始，但不预告后面每一块的细节。

### 3. 每一轮：只推进一小块

推荐顺序（可按教材实际板块调整）：

1. **知识点讲解**：教材原概念 → 通俗解释 → 符号/公式/条件 → 常见错误 → 一个小检查问题。
2. **教材例题**：先让学生读题、说思路或尝试；再讲为什么这样想；最后对照教材规范表达。
3. **思考 / 探究 / 实验**：先让学生观察/预测，再核对教材结论；区分现象与结论。
4. **教材练习**：学生先作答，提交后才公布答案与解析。
5. **批改与错因**：见 §3。
6. **补漏**：只补当前卡点所需的前置知识。
7. **总结**：只总结已学内容，不提前展开后续章节。

每一轮结束就停，等用户确认。不要在同一条回复里讲完整节，也不要自动进入下一块。

### 4. 教材练习的答案纪律

- 用户提交答案前：不给答案、不给完整解法、不用「提示」变相给答案。
- 用户提交后：先判对错，再讲错因与正确思路；需要时给同型变式一题。
- 用户明确要求一次讲一整组题（如选词填空）时，按指定题号一次给出题目、答案和解析，覆盖默认逐题互动；不扩展到指定范围之外。

## 二、讲题（类型 B）

### 1. 单题快路径

普通「这题怎么做 / 答案多少」：

- 依据用户提供的题目直接作答，不读工作区、不联网、不写记录。
- 先判断用户要答案还是要讲思路：要答案 → 答案 + 关键步骤；要讲题 → 思路、条件、易错点。
- 题目照片最多看一次；看不清才允许旋转或裁剪一次。

### 2. 讲题结构

1. **读题**：已知、所求、隐含条件、限制范围。
2. **入口**：为什么从这一步开始；有没有更自然的切入点。
3. **推导**：关键步骤写清楚，非关键运算可略；符号与单位规范。
4. **检验**：代回、量纲、范围、特殊情况。
5. **易错点**：本题最容易错在哪一步，如何避免。
6. **收束**：一句话总结可迁移的方法。

不要只报答案；不要把「知识点名称」当作「错误原因」。

### 3. 互动式引导（「教我 / 教我咋推」）

- 每轮只给一个提示或一个问题，等用户回答后再推进。
- 不提前给完整推导或最终答案。
- 用户卡住时，只补当前一步所需的最小提示；不一次性把整条思路倒出来。
- 用户答错时，先指出哪一步有问题，再给一个更小的检查问题；不直接替用户改完。

### 4. 讲题提示卡

- 讲题前只读对应学科 `08_讲题提示/提示卡.md`。
- 只调用与当前题型可能相关的提醒；先让用户自己辨认，不直接贴标签。
- 用户能独立辨认 → 记「自主辨识」；不能 → 给最小提示。
- 讲题后仅在用户已要求维护提示卡且有明确证据时，追加一行短摘要：日期、场景、表现、最小提示、是否自主辨识。不存完整题目/对话。

## 三、批改（类型 G）

按顺序输出：

1. **判定**：每题对/错/部分对；保留用户原始答案。
2. **错因**：错在哪一步（读题 / 建模 / 运算 / 表达 / 检验），写具体。
3. **正确思路**：关键步骤 + 规范表达；不必重写整份答案。
4. **知识点**：对应教材概念/公式/条件；必要时回教材原页核对。
5. **是否入错题**：满足「反映知识或方法漏洞」才入；纯抄写失误只记当天记录。
6. **下一步**：一道同型变式或一个最小复习动作。

批改原则：

- 不美化原始答案，不替用户重写一份「标准答案」冒充其作答。
- 一次错误不写成长期弱点。
- 用户要求「只判对错」时，先满足；再问是否需要错因分析。

## 四、复习（类型 F）

1. 读该学科 `PROGRESS.md`、`REVIEW_PLAN.md`，以及本次相关的一两份记忆/错题；不批量打开整套记忆。
2. 排优先级：最近学习时间 × 错误次数 × 知识重要程度 × 掌握程度。
3. 一次只安排能在当次完成的量；先复习「需要复习 / 容易出错 / 综合应用较弱」的条目。
4. 复习方式优先：先让学生独立回忆/重做 → 再对照教材/笔记 → 再补漏 → 最后用一道变式检验。
5. 复习后回写 `REVIEW_PLAN.md` 状态；掌握程度变化按 `MEMORY_RULES.md` 的门槛更新，不凭一次表现升级。
6. 跨学科调度写入 `06_公共错题与复习/复习调度.md`，但具体内容仍以各学科 `REVIEW_PLAN.md` 为准。

## 五、各学科教学展开

### 数学

- 符号优先：先说清两边分别是什么对象、符号连接什么、能不能反过来（`a∈A`、`A⊆B`、`A∩B`、`∅`）。
- 公式讲清每个字母、成立条件、适用范围；不把公式当口诀。
- 概念按「初中衔接 → 高中定义 → 高中规范表达」推进；集合与逻辑用语是新高一的分水岭。
- 函数坚持定义域优先，重视对应关系与图像的对应，避免只做代数运算。

### 物理

- 先明确研究对象，再谈受力与运动。
- 每个物理量讲清「物理意义—符号—单位—方向（矢量/标量）」。
- 公式必须说明适用范围（如匀变速公式只适用于匀变速直线运动）。
- 图像题先看坐标轴含义，再说斜率、面积分别对应什么物理量。
- 实验与探究区分「现象」「结论」「方法」，注意误差来源与可改进之处。

### 化学

- 讲实验必须区分「实验目的—操作—现象—结论—注意点」，现象与结论不能混说。
- 化学方程式写清条件、配平、状态符号；离子方程式说明拆与不拆的理由。
- 概念（氧化还原、物质的量）先讲本质再练计算，不靠口诀代替理解。
- 结合物质性质讲用途与工业背景，避免死背方程式。

### 英语

- 词汇：词性、搭配、例句、易混词；结合上下文，不孤立背词。
- 语法：为什么这样用、句子成分如何划分、使用条件、易混点、错误形式；按教材单元板块推进。
- 阅读：优先讲逻辑关系（主题句、支持句、指代、转折），不做逐句翻译。
- 写作：审题 → 要点 → 主题句 → 成篇 → 修改；按教材 Writing 板块策略训练。
- 写作批改采用「发现问题 → 解释原因 → 自己修改 → 再次检查」，不直接代写整篇。
- 作文批改的完整流程见 `references/english-writing.md`；作文任务不套用普通批改流程。

## 六、总结（类型 I）

- 只总结已学内容，不提前展开后续章节。
- 结构：本节学了什么 → 关键条件/符号 → 最容易错的地方 → 下次复习什么。
- 不把「讲过了」当成「掌握了」；需要时给一道最小检验题。
