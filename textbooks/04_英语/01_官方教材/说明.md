# 英语 · 官方教材目录说明

- `Word/`：**日常阅读的首选版本**（文字、定义、公式、关键词、例题/练习文字）。识别不到、缺字/乱码、表格/图片/公式不清或内容有误时，回 `PDF/` 原页核对。
- `PDF/`：**原版视觉与校对依据**（章节、标题、页码、图片、实验、例题、练习、排版）。Word 与 PDF 冲突时，以 PDF 原版为准。
- `教材信息/`：`教材信息.md`（档案）、`当前版本.md`（教学基准）、`版本变更记录.md`（换版本时登记，不覆盖旧文件）。
- `INDEX.md`：教材章节索引，是 Agent 检索教材的入口。

## 命名规范
`学科册次_版本_出版社_版次.pdf` / `.docx`，例如 `数学必修第一册_沪教版_上海教育出版社_2020年7月第1版.pdf`。
多版本并存时保留版本标识，禁止同名覆盖旧版本。

## 手动上传教材后的处理流程（由 Agent 执行）
1. 判断学科、教材名称、出版社、版本、册次；不能确定的写「未知」，**禁止猜测**。
2. 检查完整性：能否打开、页数、目录、章节、是否缺页、是否损坏、是否重复。
3. 放入 `PDF/` 或 `Word/`，按命名规范改名。
4. 更新 `教材信息/`、`当前版本.md`、`INDEX.md`、`00_学习控制中心/WORKSPACE_STATUS.md`。
5. 标记状态：【已核验】/【版本待确认】/【教材不完整】。
