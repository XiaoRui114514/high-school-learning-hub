# 自带教材（textbooks）

本目录随 skill 一起分发，包含四科教材的 **PDF + Word + INDEX + 教材信息**，下载 skill 后即可离线阅读，不需要另建工作区。

## 一、阅读顺序

1. **日常阅读优先 Word**：文字、定义、公式、关键词、例题/练习文字从 `Word/` 读取。
2. **Word 识别不到或内容有误时回 PDF**：缺字、乱码、表格/图片/公式不清、板块/页码不确定，都回到 `PDF/` 原页核对。
3. **页码、图片、实验、例题/练习排版与最终校对以 PDF 为准**；Word 的页码/排版不可当作教材页码引用。
4. Word 与 PDF 冲突时，以 PDF 原版为准。

> `INDEX.md`、`说明.md`、`教材信息/` 是从工作区同步的教材档案；其中提到的 `00_学习控制中心/`、`08_系统工具/` 等路径属于工作区。单独使用 skill 时，脚本用本仓库的 `scripts/`。

## 三、读取 Word

不要直接打开整份 Word（单文件 68–83 MB，含大量图片）；用 skill 自带脚本按目录、关键词或段落取文字：

```powershell
# 在 skill 根目录运行
py -3 scripts/extract_word_text.py "textbooks/01_数学/01_官方教材/Word/数学必修第一册_沪教版_上海教育出版社_2020年7月第1版.docx" --outline
py -3 scripts/extract_word_text.py <DOCX> --grep "集合" --context 1
py -3 scripts/extract_word_text.py <DOCX> --start 76 --end 95
```

- `--outline`：列出一章/一节的起始段落，先定位。
- `--grep`：按关键词定位，`--context` 控制前后段落。
- `--start/--end`：按段落序号读取一段。
- `--stats`：只看段落/表格/字符统计。
- 文字缺字、乱码、公式/表格不清时，用 `extract_textbook_page.py` 回 PDF 对应页核对。
