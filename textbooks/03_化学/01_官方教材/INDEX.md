## 一、Agent 使用规则

- 本文件是该学科**唯一**的教材检索入口：先读本文件定位章节，再只读取教材对应页，禁止整本扫描。
- `教材页码` = 书上印刷的页码（依据教材目录核对）；`PDF页码` = PDF 阅读器页序（已用章节首页抽样核验，偏移 **+6**）。
- 「核心知识点」依据教材目录与本节正文整理；**例题 / 练习 / 实验 / 探究 / 图表位置在首次学习该节时读取原页回填**，未回填前不得凭空引用。
- 日常阅读优先用 `Word/` 对应文件；Word 识别不到、缺字/乱码、图表/公式不清或内容有误时，回 `PDF/` 原页核对。教材页码、图片、实验、例题/练习排版与最终校对以 PDF 为准；需要时也可用 `08_系统工具/提取教材页.py` 读取 PDF。

#### 1.2 物质的量

- 教材页码：15（PDF 21）
- 节范围：教材页 15–21（PDF 21–27）
- 核心知识点：物质的量（n）与摩尔（mol）；基本单元与阿伏加德罗常数（NA = 6.02×10²³ mol⁻¹）；n = N/NA；摩尔质量（M，g·mol⁻¹）与 n = m/M；气体摩尔体积（Vm，L·mol⁻¹）与 n = V/Vm；标准状况（STP，273 K、101 kPa）下 Vm ≈ 22.4 L·mol⁻¹；温度、压强对 Vm 的影响；阿伏加德罗定律（同温同压同体积含相同数目的分子；V₁/V₂ = n₁/n₂）
- 教材例题：例题导引（学习指南）教材页 20（PDF 26）——320 g CH₄ 的物质的量、分子数与标准状况体积换算
- 教材练习：练习巩固 6 题，教材页 21（PDF 27）
- 实验 / 探究 / 思考：想一想（教材 17 / PDF 23）表 1.2 中 1 mol 各物质质量的数值特点与体积差异原因；书写表达（教材 17 / PDF 23）21.58 g 银的物质的量与原子个数；书写表达（教材 18 / PDF 24）水蒸气分子平均距离估算；想一想（教材 19 / PDF 25）由反应体积比推导 X 的化学式
- 图表 / 图片：表 1.1 SI 7 个基本单位（教材 15）、表 1.2 常压下 1 mol 不同物质的质量和体积（教材 16）、图 1.12 标准状况下 1 mol 气体的体积（教材 17）、表 1.3 其他条件下气体摩尔体积（教材 18）、表 1.4 甲烷燃烧反应中各物质间的定量关系（教材 19）、图 1.13 n 与 N、m、V 的关系（教材 20）
- 说明：物质的量浓度及其配制属于 **1.3 化学中常用的实验方法**（教材页 22 / PDF 28），不属于 1.2
